# SunWork — UI/UX Prototype

Một phiên bản web thứ hai để bạn so sánh với MoonWork.

## Điểm khác chính
- Brand mới: **SunWork**
- Màu sắc: tone **sun / warm / orange / yellow**
- Hero khác hoàn toàn: **1 nhân vật đứng giơ 2 tay**, phía trên có chữ **WORK** phập phồng
- Giao diện sáng hơn, ấm hơn, tươi hơn
- Tính năng khác đi một chút để so sánh:
  - **Saved Jobs** riêng cho ứng viên
  - **Portfolio Builder** thay cho CV builder
  - **Interview Plan** cho ứng viên
  - **Talent Board** cho nhà tuyển dụng
  - **Interview Board** cho nhà tuyển dụng
  - **Skill Lab** ở phần public

## Cách chạy
- Mở `index.html`
- Hoặc dùng VS Code + Live Server
